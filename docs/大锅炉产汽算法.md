# 大锅炉产汽算法

本文描述蒸汽的两条来源: 本模组的多方块蒸汽锅炉, 以及被改造成纯蒸汽驱动的机械动力原版大锅炉 (FluidTank 多方块 + BoilerData).

## 0. 术语与量纲

| 记号 | 含义                                   | 单位 |
|------|----------------------------------------|------|
| L    | 蒸汽锅炉等级                           | 级   |
| H    | 结构下方一层烈焰人燃烧室给出的热量分    | 级   |
| V    | 方块数给出的等级上限                   | 级   |
| P    | 每 tick 产汽量                         | mB/t |
| B    | 蒸汽槽存量 / 容量                      | mB   |
| W    | 水槽存量 / 容量                        | mB   |

蒸汽锅炉的等级上限, 每级所需方块数与单级产汽量都是 `SteamBoilerBlockEntity` 的常量; 两槽容量取自方块注册时给出的
`SteamEngineSpec`. 本文只写公式与判定顺序, 具体数值以常量与配置为准.

## 1. 蒸汽锅炉

蒸汽锅炉有两条互不相同的运行路径, 由结构宽度决定:

- 宽度 1: 改造前的单块运行方式. 只看正下方一台 `IHeatSource`, 按热量百分比分档取效率, 过热燃料直接产出过热蒸汽, 产汽规则与太阳能锅炉共用 `AbstractBoilerBlockEntity`
- 宽度 2 及以上: 按原版流体储罐的规则拼成多方块结构, 由下方一层烈焰人燃烧室决定等级

本章其余小节只描述第二条路径.

### 1.1 结构

蒸汽锅炉方块按原版流体储罐的拼接规则成形: 拼接由 `ConnectivityHandler` 完成, 底面必须是正方形, 边长上限与高度上限
沿用储罐, 最小的合法结构由 `SteamBoilerBlockEntity.MIN_WIDTH` 给出.

- 宽度 1 的方块不走多方块路径, 按本章开头的单块方式运行
- 控制器位于结构最底层的角块, 组件与热量判定都以控制器为准
- 拼接只与本模组的蒸汽锅炉互连, 不会和原版的流体储罐连成一片
- 不成形时方块仍可单独破碎, 掉落自身

### 1.2 两个流体槽

方块对外暴露一个双槽流体能力, 结构内任意一格都转发到控制器的槽位:

| 槽 | 内容           | 可注入 | 可抽出 |
|----|----------------|--------|--------|
| 0  | 水             | 是     | 否     |
| 1  | 蒸汽 / 过热蒸汽 | 否     | 是     |

两槽容量都等于方块数乘锅炉自身的单方块容量. 槽 0 只接受 `BoilerFluidTank.isWater` 判定的流体, 槽 1 只接受
`SlFluidTags.STEAM` 与 `SlFluidTags.SUPERHEATED_STEAM`. 外部无法通过流体能力向槽 1 注汽, 蒸汽只能由锅炉自己产出.

结构内不渲染液面, 槽内流体不进入护目镜以外的任何显示.

### 1.3 等级

热量只统计控制器正下方一层, 即底面覆盖的那 `width * width` 格. 判定在服务端按 `HEAT_SAMPLE_RATE` 的节拍执行.

```
H = 2 * 超级燃烧室数 - 非超级燃烧室数        仅烈焰人燃烧室计入
V = 方块数 / BLOCKS_PER_LEVEL
L = H <= 0 ? 0 : min(H, V, MAX_LEVEL)
```

- 只有超级燃烧状态 (`HeatLevel.SEETHING`) 计正分, 其余状态含未点燃的状态计负分
- 没有超级燃烧室时等级恒为 0, 即不产汽
- 同一层混入两种以上燃烧状态时, 非超级状态把总分拉低, 这就是降级
- 被动热源 (营火一类) 与非烈焰人燃烧室的方块一概不计入
- 方块数不够时 `V` 小于 `H`, 等级被体积夹住
- 等级内部保留小数, 护目镜显示时向下取整

### 1.4 产汽

```
P = L * 单级产汽量
产汽量 = min(P, 水槽存量, 蒸汽槽剩余空间)        水与蒸汽 1:1 换算
```

每 tick 把 `P` 累加进一个余量, 取整后按 1:1 从水槽扣水并写入蒸汽槽:

- 水槽为空或蒸汽槽已满时不产汽, 余量最多保留一个 tick 的量, 不会无限累积
- 蒸汽槽满时水继续留在水槽, 管网可以继续注水直到水槽满
- 蒸汽槽存的是另一种蒸汽时, 按 `SteamConfig.DO_OVERHEATED_STEAM_REPLACE` 决定销毁还是就地转换, 两种方式都不额外消耗水
- 产出流体由 `SteamConfig.getOutputSteamFluid` 与 `getOutputSuperheatedSteamFluid` 决定

### 1.5 过热蒸汽

过热产出不是等级的自然结果, 需要额外条件:

```
过热 = 已安装过热蒸汽组件 且 超级燃烧室数 > 0
```

- 组件是物品 `steam_letters:sh_steam_component`, 右键锅炉装入, 空手右键拆下
- 组件绑定在控制器那一格, 结构被破坏或控制器消失时直接掉落
- 生存模式装入消耗一个, 拆下归还; 创造模式装入不消耗, 拆下不掉落
- 过热时水汽比仍为 1:1, 与普通蒸汽完全相同
- 组件装在控制器上但下方没有超级燃烧室时不成立, 仍产出普通蒸汽
- 产出类型切换时余量归零, 避免旧类型的分额被算进新类型

### 1.6 护目镜

护目镜按行输出结构尺寸, 等级, 额定产汽, 储水量, 蒸汽存量与过热状态. 等级一栏显示向下取整后的整数, 内部仍按
小数参与产汽换算, 因此读数与产汽量不一定成整倍关系. 额定产汽即 `P`, 是等级换算出的名义值; 实际写入量还受
水槽存量与蒸汽槽剩余空间限制, 因此可能低于该读数.

### 1.7 持久化

水槽沿用父类的槽位键, 蒸汽槽, 组件, 产出类型与余量用独立键写入. 读档时先按父类口径反序列化, 再按方块数重设两槽容量并
重读水槽, 以免父类按原版储罐的容量口径截断水量.

## 2. 原版大锅炉: 蒸汽驱动

大锅炉不再自己烧水产汽. 它保留原版的热源判定, 应力输出与护目镜, 但水的用途只剩计量, 蒸汽只能由外部注入.

- 注入的蒸汽进入锅炉自己的缓冲, 既抬升等级也是可被抽走的存量
- 缓冲容量 = 方块数 * 缓冲基准 * `BoilerSteamConfig.BUFFER_MULTIPLIER`, 倍率为 0 时拒收任何蒸汽
- 有蒸汽时等级被顶到 `SL_MAX_LEVEL`, 供水项不再限制等级
- 缓冲被抽空后等级归零, 结构退回未加热状态
- 引擎效率沿用原版口径, 不再按名额摊薄

注入走 `SteamBoilerFluidHandler.fill`: 水交给原版槽位, 蒸汽登记给 `sl$notifySteamInput`. 抽走只有一条路径,
即 `SteamBoilerFluidHandler.drain` 从缓冲抽, 所有通过流体能力取汽的设备共享同一个蒸汽池.

## 3. 每 tick 执行顺序

蒸汽锅炉, 服务端且为控制器时:

```
1. 每 HEAT_SAMPLE_RATE tick 重扫下方一层, 重算 L
2. L <= 0: 余量归零, 结束
3. 过热条件变化: 切换产出类型, 余量归零
4. 余量 += L * 单级产汽量
5. 取整为 0, 或水槽为空, 或蒸汽槽已满: 余量收敛到一个 tick 的量, 结束
6. 产出流体未配置: 余量归零, 结束
7. 蒸汽槽存有另一种蒸汽: 按配置销毁或就地转换
8. 可写入量 = min(蒸汽槽能接受, 蒸汽槽剩余空间, 水槽存量)
9. 扣水, 写蒸汽槽, 余量减去写入量
```

## 4. 边界与不变量

| 情形               | 行为                                                     |
|--------------------|----------------------------------------------------------|
| 单块或底面不是正方形 | 不成形, 不统计热量, 不产汽                              |
| 下方没有烈焰人燃烧室 | H = 0, L = 0, 不产汽                                     |
| 只有非超级燃烧室   | H <= 0, L = 0, 不产汽                                    |
| 混合两种燃烧状态   | 非超级状态计负分, L 被拉低                               |
| 方块数不足         | V 限制 L, 产汽按 V 缩小                                  |
| 水槽见底           | 不产汽, 余量收敛                                         |
| 蒸汽槽满           | 不产汽, 水继续进水槽直到水槽满                           |
| 装了组件但无超级燃烧室 | 仍产出普通蒸汽                                       |
| 蒸汽槽存有另一种蒸汽 | 按配置销毁或转换, 不消耗额外的水                       |
| 结构被破坏         | 控制器上的组件直接掉落                                   |
| 读档               | 两槽容量按当前方块数重设, 水与蒸汽按各自键恢复           |

## 5. 实现位置

| 目标                                | 位置                                                     |
|-------------------------------------|----------------------------------------------------------|
| 拼接, 控制器, 单方块容量            | 继承 `FluidTankBlockEntity` 与 `FluidTankBlock`          |
| 双槽流体能力                        | `SteamBoilerTankHandler`                                 |
| 等级, 产汽, 过热, 护目镜            | `SteamBoilerBlockEntity`                                 |
| 组件安装与拆卸, 掉落                | `SteamBoilerBlock`                                       |
| 组件模型                            | `SteamBoilerRenderer` 与 `SlBlockPartialModel`           |
| 拼接纹理                            | `SlSpriteShifts` 与 `SteamBoilerTankModel`               |
| 大锅炉的蒸汽驱动                    | `BoilerDataMixin`, `SteamBoilerData`, `SteamBoilerFluidHandler` |

## 6. 配置项

| 配置                            | 说明                                       |
|---------------------------------|--------------------------------------------|
| `boiler_steam.buffer_multiplier` | 大锅炉缓冲容量倍率, 0 表示不收蒸汽         |
| `steam.output_steam_fluid`       | 蒸汽锅炉产出的蒸汽流体                     |
| `steam.output_superheated_steam_fluid` | 过热产出使用的流体                   |
| `steam.do_overheated_steam_replace` | 切换产出类型时, 旧蒸汽销毁还是就地转换 |
